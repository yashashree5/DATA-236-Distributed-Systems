# DATA-236: Distributed Systems

This repository contains coursework and projects for **DATA-236 – Distributed Systems**.

## 📚 Course Overview

This course focuses on the design, development, and deployment of modern distributed systems. Topics covered include:

- Big Data Distributed Systems
- Large-Scale Distributed Systems Frameworks
- Distributed Messaging Frameworks
- Building Distributed Systems with Cloud Technologies
- REST (Representational State Transfer) Service Development and Deployment
